# 📚 প্রাথমিক পাঠশালা — অধ্যায়ভিত্তিক প্রশ্নব্যাংক সংগ্রহশালা (NCTB ২০২৬)

জাতীয় শিক্ষাক্রম ও পাঠ্যপুস্তক বোর্ড (NCTB) প্রণীত **২০২৬ শিক্ষাবর্ষের নতুন পাঠ্যবই** অনুযায়ী প্রস্তুতকৃত সম্পূর্ণ অধ্যায়ভিত্তিক প্রশ্নব্যাংক।

> **বিশেষ দ্রষ্টব্য:** ২০২৬ শিক্ষাক্রমের মূল্যায়ন নির্দেশিকা অনুসারে বাংলায় কোনো সিন অনুচ্ছেদ (Passage) রাখা হয়নি; প্রশ্নগুলো সরাসরি পাঠ্যবইয়ের পাঠ ও ব্যাকরণিক অনুশীলনীর আলোকে সাজানো।
