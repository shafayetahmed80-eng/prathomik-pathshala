# 📚 পঞ্চম শ্রেণি — আমার বাংলা বই (NCTB ২০২৬ শিক্ষাবর্ষ)
## 📂 অধ্যায়ভিত্তিক প্রশ্নব্যাংক ডিরেক্টরি (Chapter-wise Question Bank)

এই ডিরেক্টরিতে জাতীয় শিক্ষাক্রম ও পাঠ্যপুস্তক বোর্ড (NCTB) ২০২৬ শিক্ষাবর্ষের মূল পাঠ্যবই **‘আমার বাংলা বই’**-এর প্রতিটি অধ্যায় বা পাঠের প্রশ্নাবলি পৃথক পৃথক মার্কডাউন ফাইলে সুবিন্যস্তভাবে সংকলন করা হয়েছে।

> **বিশেষ দ্রষ্টব্য:** এনসিটিবি ২০২৬ প্রাথমিক মূল্যায়ন কাঠামো অনুসরণ করে বাংলায় কোনো সিন অনুচ্ছেদ (Passage) রাখা হয়নি।
